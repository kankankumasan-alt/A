# 飲食店サイト テンプレート（サンプル：Trattoria Verde）

緑×白基調・スマホ対応の飲食店サイトです。今はサンプル内容で作られているので、
公開前に下記の「差し替えチェックリスト」を上から順に埋めてください。

## ファイル構成
```
restaurant-site/
├── index.html   … ページ本体
├── style.css    … デザイン（色を変えたいときは冒頭の :root 内の色コードを変更）
├── script.js    … ナビの開閉、フォームの仮動作、microCMS連携サンプル
└── images/      … 写真を入れるフォルダ（からの状態です。ご自身で作成してください）
```

## 差し替えチェックリスト（index.html内、コメント`<!-- -->`の箇所）

| 項目 | 何をするか |
|---|---|
| 店舗名 | 「Trattoria Verde」をヘッダー・フッターなど全箇所で検索して置き換え |
| キャッチコピー・本文 | hero-copy / hero-sub 等の文章を書き換え |
| LINE予約URL | `ここにLINEの予約URLを入力してください` を検索し、LINE公式アカウントの友だち追加URL等に置き換え（2箇所：ヒーロー内のボタンと、右下固定ボタン） |
| 写真 | `images` フォルダに写真を保存し、`src="images/ここに写真ファイル名を入れてください.jpg"` の部分をファイル名に書き換え（メニュー3枚＋必要ならhero背景） |
| 住所・営業時間・アクセス・電話番号 | 「店舗情報」セクションのサンプル文章を実際の情報に書き換え |
| Googleマップ | Googleマップで「共有」→「地図を埋め込む」からURLを取得し、`iframe`の`src`を置き換え |
| お問い合わせフォームの送信先 | `ここにフォームの送信先URLを入力してください` を、Formspree等のURL、またはGoogleフォーム埋め込みに置き換え（未設定の間は送信時に確認メッセージが出ます） |
| 本日の日替わりランチ | Instagram埋め込みコードを貼るか、script.js内のmicroCMSサンプル関数を有効化 |

## Vercelでの公開方法
1. このフォルダ（index.html / style.css / script.js / images）をGitHubリポジトリにアップロード
2. [vercel.com](https://vercel.com) にログインし「Add New… → Project」からそのリポジトリを選択
3. フレームワーク設定は不要（Other のままでOK）。そのまま「Deploy」をクリック
4. 発行されたURLでサイトが公開されます

GitHubを使わない場合は、Vercelの「Deploy」画面でこのフォルダをそのままドラッグ＆ドロップしても公開できます。
